# Age Calculator

## Description
A simple Python program that calculates a user's age based on the birth year entered by the user.

## Features
- Takes user input
- Calculates age
- Displays the result
- Simple and beginner-friendly

## Technologies Used
- Python

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run:

```bash
python age_calculator.py
```
